# 涨知识丨医用低剂量辐射对人体的危害有多大？

> 更新时间：2026-09-16 (UTC+8)

****‍

 

射线无处不在，人类实际上每时每刻都在接受射线的照射。正常本底地区由天然辐射源对人类造成的照射水平的估计值见下表。天然辐射源对成年人造成的平均有效剂量约为2.4 mSv。

 

1895年德国物理学家伦琴发现了X射线，人类医学史从此翻开了新的一页。随着医学生物工程的进步，借助各种影像技术，不必采用侵入的方法，而获取诊断结果。由此而带来的辐射后果，引发了种种担忧。切尔诺贝利核电站事故和日本福岛核电站核泄漏更将人类对于辐射的担忧推向了另一个高度。

 

在人类对射线的应用不久, 就发现了辐射对人体的伤害, 随之也就开始了辐射防护标准的历史。1915年德国、英国放射协会发布对医生的X 光使用导则。192 1 年英国成立x 射线和镭防护委员会。1925年举行第一次国际放射学大会。辐射在各个领域的应用越来越广，国际放射防护委员会提出一系列的防护标准及建议书。

作为防护理论的学术基础是国际放射防护委员会根据早年的科学研究提出了一个假设（LNTH:Linear No-Threshold Hypothesis）线性无阈假说。这个假说认为DNA是辐射作用的主要靶器官，辐射效应由射线能量的DNA上得沉积所引起，因此只要接受一定的照射就一定存在风险，而且这些风险是可以累积相加的。基于整体辐射剂量的限制，辐射防护实践提出辐射剂量合理达到最低的原则。目前认为低剂量辐射对人类最主要的影响就是诱导癌症。

随着研究的进步线性无阈假说受到越来越多的挑战。

首先在自然界，虽然射线无处不在，但不同的地区受到的辐射剂量不同，但是并没有发现因为本地的辐射水平不同而导致的明显健康差异。在印度、巴西和伊朗, 有超过10 mSv/a 的高辐射地区, 但在这些地区的居民中没有见到天然辐射引起有害健康效应的证据。

 

其次，该原则忽视是人体对低剂量辐射的保护下反应。在受到低剂量照射后身体通过一系列成熟的机制来处理这种辐射损伤，通过涉及150多种基因的DNA修复提供癌症保护，抗氧化生产，细胞水平上的细胞凋亡，旁观者效应，在组织以及有机体水平上对存活的受损细胞通过免疫系统去除。许多研究表明至少6种降低癌症发生率和延长寿命的机制，因受到低剂量损伤的刺激而发挥作用。俗语说：不干不净，吃了没病。本质是病原微生物对免疫系统的刺激，能在一定程度上促进健康。低剂量的照射亦然。

最后，该假设导致了一系列的风险。由于患者对射线的恐惧拒绝接受成像检查而导致误诊。或者因低照射而诊断不明，反复照射，造成医疗资源的浪费。

由细胞正常代谢过程引起的DNA自发变化水平与由于低剂量辐射引起的DNA变异相差不大。 例如，在美国平均每年3 mSv的本地照射导致每个细胞产生3-30次基因突变，一次CT扫描导致10-100次基因突变，而由于身体的正常生理代谢引起的变异比CT扫描引起的基因突变多100万倍。 

广岛-长崎原子弹辐射遗传效应随访调查表明, 父母受到0 .4 ～ 0 .6 Gy 辐射照射后, 在所研究的遗传指标上未见有统计意义的效应。对英国放射师的观察表明, 与英国其他男性医师相比, 在1920 年以后注册的英国放射师中癌症死亡率没有显现出有统计意义增加。他们的死亡率明显低于所有男性医学从业者。

因此，公众有必要排除对医用低剂量辐射的过度担忧，在需要进行放射性检查（X线、CT、SPECT、PET/CT）时，放下对射线不必要的焦虑，进行及时、精准的诊治。
